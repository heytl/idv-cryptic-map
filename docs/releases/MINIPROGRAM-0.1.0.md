## 提交与微信发布

本次提交范围为小程序源代码、测试、图标生成脚本与静态图标、workspace 依赖及锁文件、当前文档与开发归档。排除构建目录、个人 AppID 配置、环境本地文件和验收临时输出。建议提交标题：

```text
feat(miniprogram): add map gestures and persistent floor previews
```

该分支 push 不触发当前工作流的生产 Worker 部署；PR 会执行测试、构建及现有预览步骤。分支职责以 `.github/workflows/deploy.yml` 为准。

微信发布前需另行完成：真实 AppID 与生产合法域名配置、正式 `pnpm build:miniprogram`、核对输出 API / AppID / 域名校验、Android / iOS 体验版回归、上传与审核。当前没有填写正式发布提交、标签、上传版本或发布时间。
