## 6. 回滚入口

只回退最近一次 Worker 部署：

```bash
pnpm exec wrangler rollback --message "Rollback production Worker" --yes
```

明确回到 V2.1.0 稳定功能基线：

```bash
pnpm exec wrangler rollback 2a13463a-9a42-45cf-9ba6-1c2b12f1d50d --message "Rollback to V2.1.0 baseline" --yes
```

紧急回到 V2 上线前的 V1 默认首页：

```bash
pnpm exec wrangler rollback 8b4a7767-12dd-42ba-869b-f6194c03b635 --message "Emergency rollback to pre-V2" --yes
```

以上命令均针对仓库顶层的正式环境，禁止附加 `--env v2-preview`。回退 Worker 不会修改 KV 或 R2。只有确认 V2 配置本身损坏时，才从 `backups-v2/` 恢复 `config:v2:current`。
