# V3 多地图升级记录（待发布）

整理日期：2026-09-23（Asia/Shanghai）。本文记录当前工作区实现及验证，不代表生产上线。正式语义版本号、Git 标签和部署标识待发布时确定；各私有 workspace package 的版本号不等同于产品发布版本。

## 相对 V2.1 的变化

### 玩家端

- 从单一地图集合升级为游戏地图 → 模式 → 入口 → 布局，记住最近筛选条件。
- 提供地图 / 模式 / 入口条件选择及方向、通道类型筛选，保留 V2 正式分享链接跳转。
- 详情页集中展示地图，桌面最大宽度 1080px；支持全图 / 分层、缩放、拖拽、旋转、全屏和重置。
- 入口参考改为桌面侧面板 / 移动端底部弹窗；返回和入口参考使用纯文字操作，hover 仅改变文字颜色。
- 详情内外统一墨蓝灰背景，金色作为操作强调色，取消早期斜纹与外围硬边框。
- 离线包按游戏地图下载；PWA 缓存公开配置与图片。未缓存内容仍需联网。

### 后台与数据

- 新增游戏地图管理、在线访问热度统计、配置备份与恢复。
- 数据采用 `GameMap → Layout → entrances / floorImages`，V3 KV 为唯一编辑真源；V2 仅保留公开协议投影。
- `packages/server/src` 抽出内容与统计业务及存储接口；Worker 负责 Cloudflare 平台适配。
- 统计写入独立 D1，按北京时间自然日查询；仅有效详情访问计数，不计楼层 / 入口切换与离线访问，不等同于 UV 或游戏内布局出现率。
- 提供配置与图片的完整导出 / 导入，验证资源哈希；配置恢复不覆盖统计。
- V1 页面、静态配置、专用图片和旧后台 API 退出运行链路；不删除远端历史归档。

### 本轮整理

- 合并详情页两个 scoped 样式块与移动端规则，清除被覆盖的浅色弹窗及早期布局值。
- 移除 App 中未使用的预览横幅 CSS，修正页面状态、离线入口与 PWA 缓存注释。
- 同步 E2E / PWA 验收脚本到“选择入口立即查看”流程，并兼容选中按钮附带的勾选符号。
- PWA 简介由“侧门入口”更新为“多地图、多模式”。
- 恢复 README 的项目功能、操作方法、目录、开发、地图维护、部署与致谢。
- 文档索引区分当前实现与历史资料，保留原有 V2.1.0 发布归档。

## 发布前按顺序完成

1. **开发分支**：当前开发分支为 `codex/v3-dev`，提交当前工作区后推送此分支。工作流先测试与构建，再迁移预览 D1 并部署隔离的 `v2-preview` Worker；生产部署只由 `feat/admin-backend` 触发。预览 Worker 继续使用独立的预览 KV / R2，不读取或写入生产存储。
2. **配置预览 D1**：在 Cloudflare 中确认 / 创建 `idv-map-stats-preview`，然后将其 UUID 保存为 GitHub 仓库 Actions Variable `V3_PREVIEW_D1_ID`。Cloudflare API Token 还需有预览 D1 迁移权限；未设置该变量时部署步骤会明确失败。
3. **保存基线**：正式发布前备份当前 Worker 版本、V2 配置及完整图片，记录备份位置和校验信息。
4. **验收真实素材**：检查桌面、手机、平板的筛选、返回、旋转、全屏、参考面板；检查 V2 分享链接、离线包、发布与下架、统计、导出导入和配置恢复。隔离测试只用样例图片，不替代逐张素材核查。
5. **准备生产**：填写生产 D1 ID，执行迁移，核对 `TELEMETRY_ORIGIN` 与 Access；预览通过后再按生产分支流程发布。生产与预览库不得混用。
6. **上线观察并归档**：记录实际发布标识，验证公开配置、图片、后台编辑、统计和备份。回滚到旧 V2 Worker 只读取冻结 V2 基线，不包含之后的 V3 编辑；回滚前保留 V3 完整导出。

具体命令与约束见 [V3-UPGRADE.md](../V3-UPGRADE.md)。本轮未操作生产，也未创建正式产品版本标签。
