## 2026-10-22：旧页面缓存升级修复

电脑浏览器访问正式网址仍可能显示旧页面，原因是旧策略预缓存首页与注册脚本，首页导航始终读取缓存；注册又等待 window.load，且缺少对已打开旧页面的升级切换。

修复后首页在线优先、离线回退；注册脚本不再进入旧的预缓存链，页面不等待图片加载即可检查更新，回到页面及恢复网络时继续检查。新 Worker 激活时先缓存可用的最新首页，再切换已有前台页面；首次安装不强制重载，后台与登录回调不参与切换。

新增 `pnpm verify:pwa:update`，覆盖旧缓存升级、同一 Worker 下在线首页更新、离线首页与地图保留、后台草稿保留、慢图不阻塞注册，并加入部署流水线。210 项测试、类型检查、构建、现有浏览器 E2E / PWA 检查及新增升级检查通过。此节描述已验证的修复，正式部署结果以对应 GitHub Actions 记录为准。
